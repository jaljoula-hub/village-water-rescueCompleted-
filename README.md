# Village Water Rescue

A responsive HTML/CSS/JavaScript side-scrolling water collection game inspired by charity: water.

## Play
Open `index.html` in a browser or publish this folder using GitHub Pages. No server, build step, or dependencies required.

## Controls
Arrow keys: run. Space/Up: jump. Esc: pause. On phones, use the touch buttons. Tap drops to collect them.

## Scoring
Blue drop +5%, gold +25%, rock -10%. Reach 100% within 90 seconds. Reset and win confetti included.

## Assets
All art is original SVG in `assets/`: parallax backgrounds (`sky.svg`, `village.svg`, `ground.svg`), player frames (`player-idle/run1/run2/jump.svg`), drops, rock, villagers and clock icon. The player sprites face right and are flipped with `scaleX(-1)` when moving left.

## Notes
The artwork is an original SVG approximation of the supplied mockup. Works on GitHub Pages as-is (relative paths, no build step).
